## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Work

- Descriptive Statistics
- Monthly and Quarterly Sales Analysis
- Customer Demographics Analysis
- Product Category Analysis
- Correlation Heatmap
- Business Recommendations
